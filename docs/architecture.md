# Архитектура

Поток данных:

1. `generate_orders` создаёт CSV с тестовыми заказами.
2. `validate` проверяет поля и уникальность `order_id`.
3. `build_warehouse` пересоздаёт таблицы SQLite и загружает данные.
4. Представление `bi_order_performance` объединяет факт и справочники.
5. `export_dashboard` записывает агрегаты в `dashboard/data.json`.

SQLite выбран для простого локального запуска. Если переносить проект на реальные данные, вместо него можно использовать PostgreSQL, ClickHouse или облачное хранилище.
